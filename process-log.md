# Process log: personal ID page

Built with Claude (Anthropic) in one working session, 9 November 2026. This log records what the AI suggested at each step and how I responded.

## 1. Data and form

| Step | AI suggestion | My response |
|---|---|---|
| Chart type | Explained the variables a streamgraph needs (time, category, value) and that most of my reference images are kite charts, not stacked streamgraphs. | Chose to work with the kite-chart / lane form from the references. |
| Data | Proposed four strands (work, personal, education, places) and a spreadsheet template with an intensity (1–5) column. | Added a Bad–Good column myself and later a Neutral value. Expanded to six strands: personal milestones, places lived, education, work, geographic places worked, miscellaneous. |
| CV | Filled work and education rows from my CV and found publication years online. | Checked and corrected the sheet, filled personal and places rows myself. |

## 2. First drafts (static images)

| AI suggestion | My response |
|---|---|
| Two styles: black-and-white (Jencks-like) and red on black; thickness = intensity, Good solid, Bad striped. | Asked to exaggerate intensity and let strands overlap. |
| Version with equal thickness (no intensity). | Used this as the "order" state. |

## 3. The concept: order and breaking

My decision: one page with a toggle.
- **Order** (Without feelings): white background, black streams, one typeface, every stream the same weight, no intensity, no good/bad.
- **Breaking** (This time with feelings): dark background, intensity and good/neutral/bad added, strands overlap.

## 4. Iterations on the breaking state

| AI suggestion / version | My response |
|---|---|
| Streams centred and overlapping inside each strand. | Rejected: I meant overlap between strands. Took the Japanese 24h city chart as reference. |
| Thicker streams spilling into neighbouring strands. | Asked for even more overlap; strand spacing reduced. |
| Striped pattern for Bad. | Changed to thin 30° lines, then to dots (like the Japanese chart), then smaller dots. |
| Handwriting font (Caveat), hand-drawn wobble and roughening filter. | Tried, then removed both the font and the hand-drawn effect. |
| Rounder, softer stream ends. | Rejected, went back to the shorter curves. |
| Text 3× bigger in the feeling state. | Tried, went back to normal size. |
| Blue outline strokes. | Removed strokes, then brought back thin dividing strokes; final outline 1pt. |
| Colour by intensity: pink → bordeaux. | Changed colour from fill to outline only, removed the fill entirely. |
| Cyan → green, then blue → red RGB scales. | Tried both, then went back to white. Intensity is shown by thickness only. |
| Labels hidden on small streams. | Asked for every stream to be labelled, even if the text overflows. |
| Labels white. | Kept white; text on Bad (dotted) streams in RGB red. |
| Good / Bad only. | Added Neutral as a third value, drawn with thin 30° lines. |

## 5. Typography and interface

| AI suggestion / version | My response |
|---|---|
| Helvetica in order, handwriting font in feeling. | Changed several times (Instrument Serif, Playfair Display, Helvetica Narrow, IBM Plex Serif). Final: Helvetica everywhere, IBM Plex Serif bold only for my name. |
| All-caps labels. | Changed to title case, then to sentence case. |
| Text button, then a two-label switch. | Kept a switch only, with one label ("This time with feelings"); red when on. |
| Hover tooltip with box, category, years, intensity. | Removed the box and all info except the stream name; magenta in the order state; no hover in the feeling state (names written on the streams instead). |

## 6. Statement

The AI drafted a statement from our conversation. I removed sentences that were too personal or too explanatory, and replaced specific personal details with a general line about what a model cannot know.
